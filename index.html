シ / ク / フ / オ / ニ / !? だけで遊ぶ
遊びかた
  1. 枚数を決めて 引く。6種類の文字がランダムに出ます（同じ文字が何枚出てもOK）。
  2. 手札の文字をタップするとキャンバスに置かれます。
  3. 人文字にするをONにすると、1画につき1人が体を伸ばして文字を作ります（1文字あたり1〜3人）。拡大すると腕や脚まで見えます。
  4. キャンバスの文字はドラッグで移動。選ぶと回転・拡大縮小・反転・濃さ・重ね順を変えられます。文字に枠はないので、そのまま重ねれば線どうしが組み合わさります。
  5. 「オ→ォ」「ニ→二」の見立てで、小書き文字や漢数字としても使えます。
  6. 下の作れる言葉例は、今の手札の文字だけをランダムに組んだ並び。意味のあることばとは限りません。押すとキャンバスに並びます。
  7. キーボード: R=90°回転 / 矢印=微調整 / Delete=手札に戻す
